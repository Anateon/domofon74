Проверены обычные, URL/JSON-кодированные и UTF-16 представления, типовые токены, приватные ключи и личные локальные пути. Совпадений нет. ## Автоматические проверки

- `assembleDebug`, `testDebugUnitTest`, `lintDebug` — успешны; ошибок Android Lint нет. Предупреждения о более новых зависимостях и стилистические подсказки не блокируют сборку.
- 27 JVM-тестов: схемы API, несколько договоров, неизвестные события, UTC/UTC+5, формат времени без дробных секунд, объединение интервалов, жесты шкалы, HLS-плейлисты, полные сегменты, разрывы, безопасные URL и обработка AAC/ADTS.
- 8 тестов на Android 16 / API 36: 3 сценария тайм-пикера, 2 сценария диапазона экспорта, 3 сценария MP4.
- Для проверки MP4 использованы три приватных TS-сегмента из предоставленной записи: 867 видеосэмплов и 350 аудиосэмплов полностью сохранены в результате. MP4 — 2 798 376 байт, 45,107476 секунды; Android декодировал начало, середину и конец. В AAC удаляется только транспортный заголовок ADTS; SHA-256 закодированного аудио до и после совпадает. Нативный проигрыватель Android воспроизводил файл, выводил кадры и перематывал его. Отмена и повреждение следующего сегмента удаляют незавершённый результат.
- Отдельный девятый Android-тест проверил MP4, полученный полным сценарием через интерфейс и фоновую задачу: декодирование начала/середины/конца, запуск нативного проигрывателя с выводом кадров и перемотка. Тесты с приватными видео выполняются только при явной подготовке локальных файлов; эти файлы не включены в проект или APK.

## Проверка действующего сервера и приложения

Использована существующая сессия из предоставленного mitmproxy dump только для чтения. Новый код подтверждения не запрашивался; команды открытия двери не отправлялись.

- Получены список домофонов, метаданные камеры, интервалы записи и история домофона.
- Прямой эфир воспроизводился в Android-приложении.
- Тайм-пикер переводил к выбранному времени; архив воспроизводился, время в интерфейсе привязано к PROGRAM-DATE-TIME.
- Нажатие на событие открывало запись за 5 секунд до него, затем воспроизведение продолжалось. Реальные времена событий не публикуются.
- Через диалог экспорта и системный выбор папки сохранён MP4 для минутного диапазона. Полные сегменты начинались примерно на 8 секунд раньше и заканчивались на 7 секунд позже запроса, размер 4 545 920 байт; 1465 видеосэмплов и 593 аудиосэмпла. Длительность файла по Android — 76,316 секунды. Границы и длительность определяются целыми сегментами и их медиавременем, без обрезки.
- APK и исходники проверены на отсутствие литералов основных токенов из перехвата. Перехват, приватные медиасегменты и данные сессии не входят в APK.

## Что пока не проверено

- Новый вход со свежим звонком/SMS и реальное физическое открытие двери: код реализован по наблюдаемому контракту, эти действия при разработке не выполнялись.
- Многодневная загрузка на настоящем телефоне, поведение при длительной потере сети, недостатке памяти или принудительной остановке приложения. Есть обработка ошибок, отмена, проверка места и фоновая работа, но длительный полевой тест не проводился.
- Другие аккаунты, модели камер и часовые пояса. Часовой пояс исследованной камеры — UTC+5; исходящие запросы используют UTC.

При обновлении API следует сверяться с [контрактом](API.md); это не официально поддерживаемый клиент Интерсвязи.
