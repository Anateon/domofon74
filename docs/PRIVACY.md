# Данные и конфиденциальность

«Домофон 74» — неофициальный клиент. Для работы нужен ваш аккаунт Интерсвязи с доступом к домофону и камере. У приложения нет собственного сервера регистрации, аналитики или рекламы.

## Какие данные используются

- Номер телефона и код подтверждения отправляются сервису Интерсвязи для входа. На установке создаётся случайный идентификатор устройства, используемый API.
- Токены и данные аккаунта сохраняются на устройстве в зашифрованной сессии; ключ находится в Android Keystore. Случайный идентификатор установки также хранится отдельно в приватных настройках приложения и остаётся после выхода. Данные исключены из резервного копирования. Выход из аккаунта удаляет сессию и отменяет активное сохранение видео.
- Адрес, домофоны, ссылки на видео и события загружаются из аккаунта для работы интерфейса. События и список доступных записей не выгружаются автору приложения.
- Рабочая очередь загрузки хранит ID домофона, диапазон времени и выбранный пользователем путь сохранения. Токены аккаунта в параметры очереди не передаются.
- MP4 сохраняется туда, куда вы укажете в системном окне Android. Временные сегменты удаляются при завершении или обработанной отмене/ошибке. Сохранённое видео остаётся у вас после выхода из аккаунта. Если вы выбрали облачного провайдера файлов или отправили видео через «Поделиться», действуют правила выбранного сервиса.

Запросы выполняются по HTTPS к `api.is74.ru`, `cams.is74.ru`, `cdn.cams.is74.ru` и `td-crm.is74.ru`. Проверка сертификатов включена. Авторизация не пересылается произвольным хостам при перенаправлении. Приложение не добавляет журналирование HTTP-тел, паролей и токенов.

## Разрешения Android

| Разрешение | Для чего |
|---|---|
| Интернет и состояние сети | Вход, видео, события и скачивание |
| Фоновая служба передачи данных | Сохранение видео с прогрессом и отменой |
| Уведомления | Показывать ход сохранения; запрос появляется при первом экспорте |
| Удержание процессора и получение события перезагрузки | WorkManager использует их для выполнения и восстановления фоновых задач |

Доступ к микрофону, камере телефона, контактам, местоположению и всему накопителю не запрашивается. Для MP4 используется системный выбор отдельного файла.

## Что опубликовано

В репозитории и APK нет встроенного аккаунта, токенов из перехвата, телефона, реального адреса или видео домофона. Скриншоты README сняты в деморежиме с вымышленными событиями. Ключ подписи, локальные настройки SDK, перехваты и тестовые видео исключены из Git.

Перед первым публичным выпуском проведены поиск типовых секретов и точное сравнение значений из исходного перехвата с публикуемыми исходниками и распакованным APK. Это проверка конкретного выпуска, а не гарантия отсутствия любых возможных уязвимостей.

## Сообщение об ошибке

Не прикладывайте к публичному issue токены, коды входа, полный перехват или подписанные ссылки на видео. На скриншотах скрывайте адрес, номер договора, телефон и кадры камеры. Для воспроизведения проблемы обычно достаточно версии Android и приложения, последовательности действий и обезличенного текста ошибки.
